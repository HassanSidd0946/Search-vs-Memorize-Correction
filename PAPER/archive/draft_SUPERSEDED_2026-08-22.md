## Methods

### Dataset and units of analysis

We analyzed ds005189, a publicly available EEG dataset on OpenNeuro (accession ds005189, DOI `10.18112/openneuro.ds005189.v1.0.1`, license CC0) collected by Helbing, Draschkow, and Võ. Thirty participants completed an encoding session comprising two blocked tasks — visual search for a target object within a scene ("Search") and intentional memorization of a scene ("Memorization") — followed by a surprise recognition memory test.

We distinguish three units of analysis throughout this paper, and use a single consistent term for each, because conflating them produces incorrect claims about where in the session a given effect occurs:

1. **Behavioral trials.** Each subject completed exactly 50 Search behavioral trials and 50 Memorization behavioral trials during encoding (confirmed directly from each subject's encoding-phase event log), always in one contiguous block per task, with block order counterbalanced across subjects (odd-numbered subjects Search-first, even-numbered subjects Memorization-first).
2. **Epochs.** Each behavioral trial generates multiple time-locked EEG epochs at the raw-marker level; we measured this ratio directly from the raw marker files and found a mean of 4.0 epochs extracted per behavioral trial, consistent across every subject checked. We use **"epoch"** throughout this paper to refer to one row of the analysis feature array — i.e., one classified unit — and reserve **"behavioral trial"** for the underlying experimental-design unit. The two are related by, but not identical to, the ~4:1 ratio above.
3. **The analysis dataset.** The full processed dataset comprises 11,610 epochs across 29 subjects (400 epochs per subject, 200 per class on average; per-subject-per-class counts range 190–220 due to natural variation in the raw marker stream). This is the dataset every control in this paper's Results §1–§3a operates on; only §10 (subsequent memory) uses a separate, exact 50-behavioral-trial-per-task subset, constructed specifically to guarantee 1:1 epoch-to-behavioral-trial correspondence (Results §10).

Throughout this paper, positional statements such as "epoch 50 of a block" use **1-indexed counting**: epoch 1 is the first epoch of a block, and "epoch 50" is the fiftieth. We apply this convention uniformly and do not switch to 0-indexed array-position language in the prose (source code and supplementary tables may retain 0-indexed array positions, which are always exactly one less than the epoch number reported here).

One subject (sub-09) was excluded from every classification analysis in this paper. We confirmed directly, by downloading and inspecting the subject's raw files, that the continuous EEG data stream for this subject terminates after approximately 110 seconds of an intended ~48-minute recording, while the accompanying event-marker file remains fully intact for the entire intended session — indicating a data-acquisition or export failure at the source, not a defect introduced by our processing pipeline. This subject's intact marker file was still usable for the marker-timing analysis in Results §7, since that analysis requires no continuous signal. All classification analyses in this paper use the remaining 29 subjects.

### Preprocessing

Raw EEG (62 channels, 1000 Hz, BrainVision format) was band-pass filtered (1–40 Hz, IIR), resampled to 250 Hz, and epoched from −0.2 to 0.8 s relative to each relevant stimulus marker. Spatial alignment used a pooled-subject Euclidean Alignment (EA) — a single whitening transform computed from the covariance of all training-pool trials in a given fold, applied uniformly to that fold's training and held-out data. We note explicitly that this is not the same alignment implementation eventually developed later in this audit for a parametrized, subject-specific alignment mode; that later module never reached production use in any result reported here, and every number in this paper uses the pooled-only alignment described above.

**No EOG regression is applied anywhere in this pipeline, because no dedicated EOG channel exists in the source data to regress against.** Separately, and this is a distinct fact worth stating precisely: **ICA-based ocular artifact correction was available and was not performed.** The absence of a reference EOG channel does not preclude ICA-based correction — component identification can proceed using a frontal-channel surrogate (e.g., Fp1/Fp2) or a reference-free automated classifier such as `mne-icalabel` — but no such step was applied to any epoch used in this paper. We flag this explicitly as a limitation (§5), and it is what motivates the dedicated ocular-contamination analysis reported in §3b.

### Feature pipeline

For each epoch, we computed the 62×62 spatial covariance matrix (with 0.1 shrinkage toward the identity, scaled by the trace), projected it to the tangent space at the identity via matrix logarithm, and vectorized the upper triangle (weighting off-diagonal entries by √2), yielding a 1953-dimensional feature vector per epoch. Features were standardized (zero mean, unit variance, fit on the training pool only) and reduced via PCA (up to 35 components, or fewer if a fold's data matrix required it) before classification with L2-regularized logistic regression (C=1.0).

### Calibration mechanism

Every result in this paper — headline numbers under audit and every diagnostic control we ran — uses leave-one-subject-out (LOSO) cross-validation with the following per-fold protocol: after holding out a subject, 15% of that subject's own epochs (selected via a stratified split, fixed random seed) are used to fit a subject-specific "local" classifier; the remaining 85% are scored. Rather than using the local classifier directly, we blend its coefficients with those of a "global" classifier trained on the other 28 subjects' pooled data, with the blend weight (0 to 1, in steps of 0.1) selected by 3-fold cross-validation restricted entirely to the 15% calibration split. We refer to accuracy using only the global classifier — i.e., before any of the held-out subject's own labeled data is used — as **pre-calibration accuracy** (`pre_cal`), and accuracy using the blended, subject-adapted classifier as **post-calibration accuracy** (`post_cal`).

This distinction is the single most consequential methodological fact in this paper. A pipeline of this design is properly described as **few-shot subject-adaptive**: every reported "decoding" number is produced after the model has already seen 15% of the labels it is being asked to predict for that specific subject. It is not a subject-independent, zero-shot decoding result, regardless of how the calibration step is described. We report `pre_cal` and `post_cal` separately for every result in this paper, without exception, so that a reader can distinguish what the classifier can do with no information about the held-out subject from what it can do with a small amount.

We also note, for completeness, that two model branches — a spatial classifier operating on the tangent-space features described above, and a separate temporal branch based on a state-space (Mamba) architecture operating on the raw aligned signal — were planned as a joint dual-branch architecture in earlier stages of this project. We found, on inspecting every script examined in this audit, that the two branches were never in fact jointly trained in any script that produced a reported number; only the tangent-space spatial branch's outputs are load-bearing for any result in this paper.

### Evaluation protocol, seed conventions, and statistical hardening

Every new diagnostic control introduced in this audit (Results §3, evidence lines 3–10, and §3a/§3b) uses a single fixed random seed (42), evaluated across all 29 eligible subjects' LOSO folds, unless an explicit, pre-registered exclusion criterion removed a subject from a specific analysis (Results §10). The 70.78% headline figure audited in evidence line 1 is drawn from a pre-existing results artifact (`results_condition4_matched_spatial_control.json`) that predates this audit; it contains exactly 29 fold entries, indicating a single evaluation pass across all 29 LOSO folds rather than a multi-seed average, though the specific seed used for that original run is not separately documented in this project's own audit trail. We are explicit about this because a 5-seed protocol *is* used elsewhere in this paper (the ocular-ablation control's `unablated` reference arm, §3b, seeds {42, 101, 202, 303, 404}), and that arm's 5-seed mean (71.46%) differs numerically from, and should not be conflated with, the 70.78% headline figure — the two are separate runs of structurally similar but not identical code paths.

Partway through this audit, a design flaw in one control (detailed in §6) revealed that a plausibility check phrased only as "accuracy lies in [0,1]" is not sufficient to catch a classifier that has learned nothing beyond the majority-class base rate of an imbalanced comparison. From that point forward, every classification result in this paper additionally reports class balance, the majority-class rate, accuracy relative to that majority-class rate, and balanced accuracy (or AUC, for the most severely imbalanced comparison in §3, evidence line 10); any comparison found to fall outside a 45/55 class-balance band is either redesigned to restore balance or explicitly declared an imbalanced design with balanced accuracy or AUC reported as its primary metric.

Finally, this paper adheres throughout to a pre-registration discipline: every interpretive threshold applied to a result — a "this counts as evidence of X" rule — was recorded, in writing, before the corresponding analysis was run, and is reported here exactly as it fired, even in the three instances (§6) where subsequent inspection showed the pre-registered rule itself to have been mis-specified. In each of those three cases we report both the original, mechanically-applied verdict and the correction, rather than silently substituting the corrected reading for the original one. The complete, dated record of every threshold in this paper is available as supplementary material (see Data & Code Availability, §9); it is what allows the three disclosed corrections in §6 to be read as evidence of this discipline working as intended, rather than as post hoc inconsistency.

## Results

We report ten lines of evidence, in the order in which they build the paper's argument, followed by two dedicated subsections: the block-level confound stack that remains after the first nine lines are accounted for (§3a), placed immediately before evidence line 10 because line 10's status as a confound-free control only follows from it, and a set of independent controls ruling out ocular contamination as an alternative explanation (§3b).

### 1. The 70.78% headline under nominal LOSO

Under a standard 29-fold LOSO evaluation of the Search-versus-Memorization contrast, with the calibration procedure described in Methods, our initial analysis of this pipeline reported 70.78% mean post-calibration accuracy (matched spatial-only control; standard deviation 11.86 percentage points across the 29 folds) as evidence of decoding. This is the number that motivated the remainder of this audit.

### 2. Pre-calibration accuracy is at chance: the protocol is few-shot subject-adaptive, not subject-independent

On the identical fold structure that produced the 70.78% figure above, mean **pre**-calibration accuracy — the classifier's performance on a held-out subject before any of that subject's own labels are used — was 52.01% (standard deviation 5.45 points), statistically indistinguishable from the chance level of a balanced two-class problem. The entire 18.77-percentage-point lift from `pre_cal` to `post_cal` is attributable to the within-subject calibration step described in Methods. We treat this as the paper's first and most direct correction to how this pipeline's evaluation protocol should be described: it is not subject-independent decoding.

### 3. Cross-subject transfer remains at chance across five structurally different configurations

We tested five further variants of the real Search-versus-Memorization contrast, each designed to remove a different candidate source of leakage or artifact from the standard LOSO fold structure: restricting comparisons to within-block-position-matched epoch subsets (`pre_cal` = 0.5083); training and testing only within a single block-order parity group rather than the standard mixed-parity pool (`pre_cal` = 0.5303); training on one parity group and testing on the other (`pre_cal` = 0.4839, averaged over both directions); and excluding a data region identified later in this audit (`pre_cal` = 0.4916; see evidence lines 6–9). Together with the unrestricted figure from evidence line 2 (`pre_cal` = 0.5201), these five values span 0.4839 to 0.5303 — every one within about three percentage points of chance (the largest deviation, 0.5303, is 3.03 points above 0.50). We regard this as the firmest single claim in this paper: under no manipulation we tried, using twenty-eight other subjects' data, does this feature pipeline carry a detectable subject-general representation of which task a held-out subject was performing.

### 4. A pseudo-label carrying zero task content reaches the same calibrated accuracy as the real contrast

To test whether the 70.78% figure reflects task content specifically, we constructed a pseudo-label with no relationship to task identity: within a single real task block, held constant, we split epochs into an "early" pseudo-class and a "late" pseudo-class by their chronological position, and ran the identical calibrated LOSO pipeline on this pseudo-contrast (both real classes tested separately and averaged). This zero-task-content pseudo-contrast reached `post_cal` = 71.12%, statistically indistinguishable from the real contrast's 70.78%, with `pre_cal` = 64.18% — above chance, unlike the real contrast's pre-calibration figure. We note here, ahead of its full development in evidence line 7, that this above-chance `pre_cal` is itself an instance of the rest-break signature identified below: an early/late split of an approximately 200-epoch block places the block's rest-break region (§7) disproportionately within the "early" pseudo-class, at a point in the underlying dose-response curve (evidence line 6) that is already well past the transition from chance to the elevated plateau.

### 5. An interleaved pseudo-label collapses to chance: the effect is temporal, not an artifact of pseudo-labeling per se

To rule out the possibility that any within-block pseudo-split produces elevated accuracy regardless of its temporal structure, we constructed a second pseudo-contrast using the same block and the same real task held constant, but alternating the pseudo-label every epoch (odd/even interleaving) rather than splitting early from late. This near-zero-temporal-separation pseudo-contrast collapsed to chance (`pre_cal` = 0.5085, `post_cal` = 0.5023), confirming that the effect in evidence line 4 depends specifically on temporal separation between the two pseudo-classes, not merely on the presence of a pseudo-label.

### 6. Excluding an early epoch window collapses every pseudo-contrast to chance at every temporal scale tested

We next parametrized the pseudo-label construction from evidence lines 4–5 continuously: alternating runs of length *k* epochs (*k* = 1, 2, 5, 10, 25, 50, 100), converting *k* to real elapsed seconds using each subject's own measured inter-trial interval. The resulting curve — flat near chance for separations under approximately two minutes, rising to a plateau around 0.64 `pre_cal` by *k* = 100 — was originally read, via a post hoc rank-correlation analysis (Spearman ρ = 0.86, one-sided p = 0.0068; paired Wilcoxon contrast between the low- and high-separation halves of the sweep, p = 3.7×10⁻⁹), as evidence that decodability scales with temporal separation between pseudo-classes.

We subsequently re-ran this identical sweep after excluding the first 50 epochs of each block, per subject, from every pseudo-label construction — 50 epochs being approximately the first quarter of each ~200-epoch block, and, as we establish directly in evidence line 7, the location of a specific structural discontinuity. Under this exclusion, the curve collapsed to chance at every value of *k* tested (`pre_cal` between 0.4974 and 0.5037 across all seven values). We report this alongside, not in place of, the original temporal-separation reading above: the numeric trend in the unexcluded sweep is real and was correctly detected, but the mechanism producing it is not temporal separation between pseudo-classes — it is concentration of a specific, structurally-locatable epoch window within one of the two pseudo-classes, which we identify directly below. The temporal-separation interpretation is withdrawn.

### 7. A rest-break discontinuity, replicating in all 30 subjects examined, at epoch 50 of every block

Motivated by evidence line 6, we inspected the raw BrainVision marker files directly, independent of any classifier, for a structural explanation of why excluding the first 50 epochs of each block removes the effect. In every one of the 30 subjects for whom we obtained raw marker files — including the subject excluded from all classification analyses above, whose marker file remains fully intact despite its truncated continuous signal — the single largest interval between consecutive epoch-onset markers within a block falls at epoch 50 (29 of 30 subjects) or epoch 55 (the remaining subject), with a magnitude 5.6 to 69.0 times the block's own median inter-epoch interval (absolute duration 8.3 to 239.5 seconds, against a typical inter-epoch interval of 3–5 seconds). Converting to the behavioral-trial unit defined in Methods (approximately 4.0 epochs per behavioral trial), this discontinuity falls at approximately the twelfth or thirteenth behavioral trial of each 50-trial block.

This pattern — one large, non-recurring gap per block, at a highly consistent location, with no comparable gap elsewhere — is consistent with a self-paced rest break inserted after approximately the first quarter of each block; we describe it this way, rather than as a confirmed instruction-screen event, because the raw marker stream contains no explicit break or comment marker distinguishing it from an ordinary epoch-onset event, only its anomalous duration.

### 8. A within-block split across this discontinuity reaches within 0.04 of the true task-boundary accuracy, at matched sample size, class balance, and temporal span

To test whether the true task boundary (the transition from the Search block to the Memorization block, or vice versa) carries decodable information beyond generic proximity to a structural discontinuity of this kind, we constructed seven further contrasts using a fixed-size symmetric window (an equal number of epochs immediately before and immediately after a candidate split point, common across all seven positions so that sample size, class balance, and temporal span are identical by construction): three positions at 25%, 50%, and 75% through each of the two blocks, plus the true block boundary itself under the same windowing. Positions whose window straddled a discontinuity of the kind identified in evidence line 7 — including the true boundary, and the 25%-through-block positions in both blocks — reached substantially higher balanced accuracy (0.86–0.90) than positions sitting entirely within the steady-state middle of a block (0.54–0.56). Most notably, the window entirely inside a single block that happened to straddle that block's own rest-break discontinuity (§7) reached 0.8585 balanced accuracy, against the true task boundary's 0.8968 — a difference of 0.04, despite this pseudo-contrast carrying no task-content difference whatsoever, both classes drawn from the same task and the same block.

### 9. Removing the rest-break region does not reduce the real contrast's accuracy

The four results above establish that a rest-break-proximate discontinuity, not temporal separation or task content, explains why pseudo-contrasts of this kind reach high calibrated accuracy. This raised a direct question the preceding evidence does not answer: does the same discontinuity explain the real Search-versus-Memorization contrast's accuracy as well? We tested this directly by dropping the first 50 epochs of each block, per subject — removing the same epoch window implicated in evidence lines 6–8 — and re-running the real contrast through the identical calibrated pipeline.

The real contrast's accuracy was **not** reduced by this exclusion: `post_cal` = 0.7215 (balanced), statistically unchanged from the unrestricted figure of 0.7078 reported in evidence line 1; `pre_cal` = 0.4916 (balanced), still at chance, consistent with evidence line 3. We regard this result as load-bearing for the paper's overall claim, not as a footnote: it demonstrates directly that the rest-break mechanism identified in evidence lines 6–8, while sufficient to explain the pseudo-contrast findings, is **not** sufficient to explain the real contrast. Once the rest-break region is excluded, what remains to explain the real contrast's post-calibration accuracy is the block-level confound stack detailed immediately below.

### 3a. The block-level confound stack

Evidence line 9 rules out the rest-break discontinuity as a complete explanation for the real contrast. What remains is a set of four structural properties of the Search-versus-Memorization contrast, all of which differ systematically between the two blocks being compared, all of which are simultaneously present in every epoch of the real contrast, and none of which can be independently varied within this dataset's design:

1. **Task instruction.** The Search and Memorization conditions differ by task instruction by definition; this is the variable the contrast is nominally designed to isolate, and it cannot be held constant while varying anything else.
2. **Stimulus set.** Within a single subject, the set of scenes and objects shown during the Search block is entirely disjoint from the set shown during the Memorization block — no item appears under both conditions for a given subject. Taken in isolation, within one subject, this disjointness is a genuine, unremovable confound: stimulus identity and task class are perfectly collinear for that subject. What prevents this confound from being exploitable by a classifier trained across the pooled cross-subject LOSO training set is that the same approximately 100 stimuli recur across the cohort, assigned to the Search or Memorization condition differently for different subjects — we confirmed this directly, finding 21 distinct stimulus-to-condition assignment patterns across the 30 subjects, independent of block-order counterbalancing. This cross-subject counterbalancing means no single stimulus reliably predicts task class *across* subjects, even though it does so perfectly *within* any one subject; it prevents this specific pipeline's cross-subject training pool from exploiting stimulus identity as a shortcut, but it does not remove the confound from the design.
3. **Session half.** For every subject, the Search-versus-Memorization contrast is also, unavoidably, a first-half-versus-second-half-of-session contrast: whichever task a subject performed first occupies the earlier half of the recording, and the other task the later half.
4. **Post-break state.** Independent of the within-block rest-break discontinuity addressed in evidence lines 6–9, the two blocks are separated by an inter-block break of approximately 400 seconds — substantially longer than the within-block rest break — that the second block follows and the first does not, regardless of whether each block's own internal rest-break region has been excluded.

These four properties are mutually confounded by the design of the underlying experiment, and no manipulation available within this dataset can vary one of them while holding the other three fixed. We regard this confound stack, not the rest-break mechanism addressed above, as the best remaining candidate explanation for evidence line 9's result, and we treat it as unresolvable using any control available in this dataset.

### 10. A confound-free control — subsequent memory — is null, and underpowered

The confound stack in §3a raises a natural question: is there any contrast available in this dataset that is simultaneously within-block, within-task, within-stimulus-set, and within-session-half — i.e., free of all four confounds at once? Subsequent memory (whether a studied item was later remembered or forgotten, established via a validated linkage between each subject's encoding-phase behavioral trials and their later recognition-test judgments) is such a contrast: remembered and forgotten items are interleaved within the same block, under the same task instruction, drawn from the same stimulus set, in the same half of the session.

Because this analysis requires an exact 1:1 correspondence between epochs and behavioral trials, which the standard analysis dataset (§Methods, unit 3) does not guarantee, we constructed a separate epoch subset here using only the marker code confirmed to fire exactly once per behavioral trial in every subject (yielding exactly 50 epochs per task per subject, one per behavioral trial, in chronological order).

We tested this contrast within Search behavioral trials only, within Memorization behavioral trials only, and pooled across both, using AUC as the primary metric given the severe class imbalance inherent to this contrast (forgotten items ranged from 0% to 18% of trials per subject per condition), with any subject contributing fewer than 10 minority-class trials to a given condition excluded from that condition, computed and fixed before any classification was run. The within-Search condition could not be evaluated at all: not one of the 29 subjects reached the 10-trial minority threshold for Search trials specifically — itself a direct behavioral replication of this dataset's own previously-reported finding that search-encoded items are remembered better than intentionally memorized ones, appearing here as a power failure rather than as a separate measurement. The two conditions that could be evaluated found no detectable signal: within-Memorization AUC = 0.4968 (95% bootstrap confidence interval [0.4489, 0.5423], 13 subjects), and pooled AUC = 0.5141 (95% CI [0.4760, 0.5547], 21 subjects) — both intervals comfortably containing 0.5.

We are explicit that this null result is a statement about statistical power, not evidence against subsequent-memory effects existing in this dataset or paradigm: with 0–18% of trials in the minority class per subject, this design has limited ability to detect an effect of any true size, and the absence of a detectable signal here does not bear on whether the effect exists.

### 3b. Alternative explanations considered and ruled out: ocular contamination

Given the absence of any EOG-regression step in this pipeline and the availability-but-non-use of ICA-based correction (Methods), we conducted three independent, pre-registered tests for ocular contamination as an alternative explanation for the real contrast's accuracy, each addressing a different signature such contamination would be expected to leave.

First, we compared accuracy with the nine most ocular-proximal (frontal and frontopolar) channels ablated against accuracy with all channels retained, situating the resulting drop against a null distribution built from twenty draws of nine randomly-selected channels from the remaining montage. **On the single-seed (42) basis used for the null-distribution comparison, the frontal-specific drop was 1.06 percentage points, falling at the 90th percentile of that null distribution (one-sided p = 0.143) — not meeting our pre-registered significance threshold of p < 0.10.** We report a further figure alongside this, numbers first: on a separate five-seed basis (seeds {42, 101, 202, 303, 404}), the mean frontal-ablation drop was 2.27 percentage points — larger than every one of the twenty random-channel-ablation drops in the null distribution, whose maximum was 1.11 percentage points. We have not fully reconciled why the single-seed comparison (1.06 pp, not significant) and the five-seed comparison (2.27 pp, exceeding the entire null range) diverge this much; seed 42 is, on inspection, a comparatively low draw for the unablated arm and a comparatively high draw for the frontal-ablated arm, which together account for its smaller apparent drop, but a full explanation would require the covariance between the two arms' per-seed accuracies, which is not currently available from this analysis's output. We flag this honestly as an unresolved discrepancy rather than resolving it in either direction. It does not affect this paper's conclusions: the contrast this test was designed to gate — the real Search-versus-Memorization contrast as a task-decoding result — is not, per evidence lines 1–9 above, a claim this paper depends on being clean of confounds in the first place.

Second, we correlated each epoch's classifier decision margin against a surrogate ocular-movement signal derived from frontal channel differences. Signed decision margin against this surrogate correlated at Spearman ρ ≈ −0.085; the absolute value of the decision margin against the same surrogate correlated at ρ = −0.015 and +0.040 across two surrogate variants. Both quantities are well below our pre-registered threshold of |ρ| ≥ 0.2 for a "strong" relationship.

Third, we extended an initial single-subject observation of elevated signal variance at frontopolar relative to central-parietal channels to the full cohort, and found it did not replicate: a mean gap of 18.30% at frontopolar sites against 8.83% at central-parietal sites, with only 16 of 29 subjects showing the same directional pattern as the original single-subject observation (Wilcoxon signed-rank p = 0.137, not significant) — indicating the original observation was an outlier in magnitude rather than a cohort-wide effect.

Taken together, these three independent tests found no significant evidence of ocular-artifact contamination, with the seed-basis discrepancy in the first test disclosed above as an open question rather than resolved.

## 4. The diagnostic protocol as a reusable recipe

The evidence in §3 was assembled reactively, one control motivating the next. Extracted from that sequence, it forms a checklist independent of this dataset, applicable to any blocked-design EEG or BCI decoding pipeline that uses within-session per-subject calibration:

1. **Always report pre-calibration accuracy alongside any calibrated number.** A single post-calibration figure cannot, by itself, distinguish subject-independent decoding from few-shot subject adaptation; the two require entirely different claims in a paper's abstract.
2. **Before trusting a real-contrast result in a blocked design, test a temporally-matched, zero-task-content pseudo-label.** If a pseudo-contrast carrying no task information reaches comparable calibrated accuracy to the real contrast, the real result cannot be attributed to task content without further work.
3. **Vary pseudo-label temporal separation parametrically, not as a single two-point comparison.** A two-point comparison (e.g., one pseudo-split reaching high accuracy, one reaching chance) is consistent with many underlying mechanisms; a full parametric sweep, as in §3 evidence line 6, is what let us distinguish a smooth temporal-separation gradient from a localized structural discontinuity.
4. **Before excluding, or interpreting, any data region as a "transient," identify what it structurally is.** Raw marker-timing inspection (§3 evidence line 7) identified a specific, reproducible event; had we instead assumed a smooth decaying process from the dose-response curve's shape alone, we would have drawn the wrong mechanistic conclusion, as our own first attempt at this exact analysis did.
5. **When a claimed effect is between-block, do not treat a within-block manipulation as informative about it by default.** If a within-block manipulation leaves a between-block effect unchanged, as in §3 evidence line 9, that is itself informative — but it must be checked and reported explicitly, not assumed from an unrelated within-block control's result (§6, mis-specification 3).
6. **Harden every classification report with class balance, majority-class rate, balanced accuracy, and AUC where appropriate.** A plausibility check phrased only as "accuracy lies in [0,1]" will not catch a classifier that has learned nothing beyond an imbalanced comparison's base rate (§6, mis-specification 2).
7. **Where a genuinely confound-free contrast exists in the data, test it explicitly.** Ruling out one explanation after another leaves an ever-narrowing set of untested alternatives; a confound-free positive control (§3, evidence line 10, subsequent memory) is a stronger form of evidence than exhausting the space of things a result is not.

## 5. Limitations

**Alignment scope.** Every result in this paper uses the pooled-subject Euclidean Alignment described in Methods, not the parametrized, subject-specific alignment mode developed later in this project's broader codebase but never brought into production for any result reported here. Our conclusions are conditional on this specific alignment choice and have not been tested under the alternative.

**Single-seed basis.** With the exception of the pre-existing 70.78% headline figure (§3, evidence line 1, seed protocol undocumented) and the ocular-ablation control's five-seed reference arm (§3b), every new diagnostic control in this paper uses a single fixed seed (42). This is a deliberate cost tradeoff for a diagnostic audit of this scope, disclosed here rather than presented as a full multi-seed protocol.

**ICA was not performed.** As noted in Methods, ICA-based ocular artifact correction was available to this pipeline — via a frontal-channel surrogate or a reference-free automated classifier — and was not applied to any epoch used in this paper. The three independent ocular-contamination tests reported in §3b found no significant evidence of contamination without ICA correction, but we cannot rule out that a smaller residual ocular contribution, below the sensitivity of those three tests, would be further reduced by ICA cleaning that was not attempted here.

**Subsequent-memory power.** The null result in §3, evidence line 10, is underpowered by construction (0–18% minority-class trials per subject per condition) and cannot be extended to a claim that subsequent-memory effects do not exist in this or similar paradigms.

**Rest-break mechanism, unestablished cause.** We identify the rest-break discontinuity (§3, evidence line 7) as a structural, reproducible timing event, but we do not establish its cognitive or physiological cause (arousal shift, re-orientation after a pause, electrode-impedance drift during the pause, or some combination) — only the timing coincidence between this event and the pseudo-contrast findings of evidence lines 4–8.

**Fixed-count versus proportional timing.** We cannot distinguish, from the data available, whether the rest-break discontinuity occurs after a fixed count of epochs or trials, or at a fixed proportion of each block's length, because the observed block lengths in this dataset (190–220 epochs) vary too narrowly to separate the two hypotheses.

**The block-level confound stack is unresolvable in this dataset.** The four-member stack identified in §3a (task instruction, stimulus set, session half, post-break state) cannot be decomposed using any control available in ds005189; this is a limitation of what this audit can conclude about the real contrast's residual accuracy, not merely a results finding.

**Ocular-ablation seed-basis discrepancy.** As reported in §3b, the single-seed and five-seed bases for the frontal-channel-ablation test disagree by a factor of roughly two (1.06 pp versus 2.27 pp), and we have not identified the source of this disagreement. This is disclosed as an open item; it does not, however, gate any conclusion in this paper, since the contrast it was designed to test is not itself a claim this paper makes.

## 6. Three disclosed criterion mis-specifications

This paper's pre-registration discipline (Methods) caught its own failures three times over the course of this audit. We present all three here as a methodological contribution in their own right, not as an appendix of errata: each is reported with the original, mechanically-applied verdict alongside its correction, modeling the practice recommended in §4, item 4 above.

**1. Strict pointwise monotonicity (§3, evidence line 6).** We originally pre-registered a strict pointwise-ordering test for the dose-response sweep: every consecutive pair of points in the seven-value curve had to be non-decreasing. This criterion failed — small (0.007–0.011) fluctuations at two of the seven points, attributable to single-seed noise, broke the strict ordering despite the underlying curve being an unambiguous flat-then-step pattern. We recorded this failure exactly as it occurred (verdict: not met) and did not delete or replace it. We then applied a post hoc, explicitly-labeled correction — a Spearman rank correlation with a subject-level bootstrap confidence interval, and a paired two-group contrast between the low- and high-separation halves of the sweep — both robust to the specific noise pattern that broke the pointwise test, and both confirmed a strong, significant trend. This correction was itself later superseded in kind, though not in the numbers it reported: the trend these more robust tests correctly detected turned out, once we identified its mechanism (§3, evidence lines 6–7), to reflect epoch-window concentration rather than temporal separation.

**2. A balance-free experimental design (§3, evidence line 8's underlying construction).** Our first attempt at the boundary-position analysis in evidence line 8 let each shift position's pseudo-class sizes vary freely with shift location and block length. This produced severe, uncontrolled class imbalance (up to a 1451:10159 split at the most extreme positions), and every reported accuracy from that first attempt tracked the majority-class base rate rather than any genuine boundary-privilege signal — a design flaw we caught only on direct inspection of the per-fold results, not from any automated check available at the time. We logged this attempt as invalid and did not cite any verdict from it. The correction was twofold: we redesigned the analysis with a fixed symmetric window guaranteeing exact 50/50 balance by construction (the version reported in §3, evidence line 8), and we adopted, from that point forward, the class-balance and balanced-accuracy reporting standard described in Methods and applied throughout the remainder of this paper.

**3. Equating "survives a within-block manipulation" with "genuine task signal" (§3, evidence line 9).** We pre-registered a rule stating that if the real contrast's accuracy survived removal of the rest-break region at or above a fixed threshold, this would constitute evidence of genuine task signal that the rest-break artifact had been masking. The rule fired exactly as written — the real contrast's accuracy did survive this removal (§3, evidence line 9) — but the inference the rule implied does not follow. The pseudo-contrasts that collapsed under the same removal (§3, evidence line 6) were within-block constructions; the real contrast is a between-block comparison, and a within-block manipulation cannot be informative about between-block confounds (task instruction, stimulus set, session half, post-break state; §3a) that it does not touch. We report the fired branch exactly as computed, alongside this correction, rather than allowing the mechanically-correct verdict to stand as an unqualified positive finding. This is the mis-specification that directly motivated both §3a's confound-stack analysis and §3, evidence line 10's confound-free control.

## 7. Discussion

**When is a "subject-independent, calibrated" decoding claim actually a subject-adaptive one?** The pipeline audited in this paper is not unusual in its use of within-session, per-subject calibration; such designs are common in EEG-based brain-computer interface work, where some degree of subject-specific adaptation is often necessary for practical performance. What distinguishes a defensible use of this design from the one we audit here is whether the paper reporting it also reports pre-calibration accuracy. A reader cannot recover this distinction from a paper's stated evaluation protocol alone — "leave-one-subject-out cross-validation" describes both a genuinely subject-independent evaluation and the few-shot subject-adaptive protocol we describe in Methods, and only the pre-calibration number (§3, evidence line 2) distinguishes them.

**Distinguishing a structural artifact from a vague drift confound.** Blocked-design confounds — fatigue, vigilance decline, electrode-impedance drift over the course of a session — are a recognized concern in the EEG decoding literature, typically discussed as a diffuse, session-long process. Our contribution here is narrower and more specific: we show that a substantial share of the apparent effect in this dataset is attributable not to a diffuse drift but to a single, structurally-locatable, reproducible discontinuity (§3, evidence line 7), identifiable directly from raw marker timing independent of any classifier, and we demonstrate a protocol (§4) for finding this kind of event rather than assuming its existence or its absence. At the same time, we show that identifying and controlling for this one mechanism is not sufficient on its own to explain the real contrast (§3, evidence line 9) — a caution against treating the discovery of one structural artifact as a complete explanation once found.

**What this paper does not claim.** We do not claim that search-superiority or subsequent-memory effects are absent from this dataset or from this experimental paradigm generally; our null result in §3, evidence line 10 is a power statement (§5), not a claim about the absence of an effect. We do not identify a single, definitive cause of the real contrast's residual post-calibration accuracy; §3a describes an unresolved, mutually-confounded stack of four candidate explanations, not a resolved mechanism. And, as stated at the outset of this paper, we do not critique the original dataset's collection or the published analyses of its original authors, who used different methods and made different claims than the pipeline we audit here; our subject throughout is our own pipeline's behavior on this dataset, not the dataset or its collectors.

## 8. Conclusion

A blocked-design EEG contrast evaluated under within-session per-subject calibration produced a headline decoding accuracy that we show, across ten independent lines of evidence, is not diagnostic of task content. Cross-subject zero-shot accuracy never exceeds chance under any of five structurally different test configurations; a substantial share of the calibrated result is explained by proximity to a previously-undocumented, structurally-locatable rest-break discontinuity that replicates in all thirty subjects examined; and the portion of the result that survives removing this discontinuity is attributable to a stack of four block-level confounds that this dataset's design cannot separate from any genuine cognitive signal. A confound-free control, available for exactly one contrast in this dataset, detected no signal, though it is underpowered to speak to the question either way. Beyond this specific dataset, we offer the sequence of controls that produced these findings as a reusable diagnostic protocol (§4) for any blocked-design decoding pipeline using within-session calibration — a design choice common enough in this literature that the failure mode we document here is unlikely to be unique to the one dataset we examined.
