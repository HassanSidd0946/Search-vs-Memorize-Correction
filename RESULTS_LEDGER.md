**A second, more serious finding surfaced while confirming this**: `draft.md` line 39 already reads *"This yields 50 epochs per task per subject, 2,900 epochs total"* — the **correct**, current, uniform-50 figure, with no sub-01 exception. `build_latex.py`'s own `TEXT_FIXES_2` block (comment: *"N1: epoch-count contradiction. The generator does not merely pass through `draft.md`'s staleness; in this one instance, it introduces a regression `draft.md` itself didn't have, based on a "verification" against a source (`STATUS.md`) already established (GATE C15) to be stale. `build_latex.py:361-372` is itself now a defect requiring a fix, not just a pass-through of `draft.md`'s existing content.
