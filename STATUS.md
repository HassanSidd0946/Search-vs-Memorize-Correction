## TIER-1 MANUSCRIPT CORRECTNESS DEFECT (flagged 2026-08-19 — read this before drafting or citing anything about the evaluation protocol)

**The manuscript's description of the evaluation protocol is false as written.** Text describing the held-out subject as "held out entirely," with "zero test-subject leakage into any stage," and evaluation as "strict subject-independent" does not match what the code actually does.

**What actually happens:** after a subject is held out for a LOSO fold, **15% of that subject's own labeled trials are used to fit a personalization step** (`fit_shrinkage_classifier`'s per-subject-blended LogisticRegression) before the remaining 85% is scored. This is confirmed by:
- Every fold's `pre_calibration_acc` (the true zero-shot number, before this step) landing at or near chance (0.40–0.53 in F-OCULAR(a)'s fold logs; mean 0.51–0.52 across the 29-fold files audited in RESULTS_LEDGER.md's **L009**), while `post_calibration_acc` (after the step) is the ~0.71 number actually reported.
- F-PARITY (ledger **L003**) independently confirms near-/below-chance cross-subject transfer (0.4927 / 0.4750, mean 0.4839) with **no calibration step at all** — a second, structurally different control pointing at the same conclusion.

**This is not a leakage bug.** The calibration split is trial-disjoint, label-free of the test set, and F-LEAK (ledger **L001**) already verified no leakage across this exact boundary. **The pipeline is legitimately FEW-SHOT SUBJECT-ADAPTIVE, not subject-independent** — a real, defensible, commonly-used BCI methodology. The defect is entirely in how the manuscript *describes* it, not in the method itself.

**Affected manuscript sections (do NOT touch LaTeX yet — Phase 3 is still blocked; this is a flag for when Phase 3 opens):** the abstract, Section IV-A (evaluation protocol description), and the "walk-up-and-use" / zero-calibration motivation framing in Section I — all currently describe or imply zero-shot subject-independent performance and must be rewritten to describe few-shot subject-adaptive calibration accurately once Phase 3 is approved.

**Supporting documentation:** exact calibration mechanism (how the 15% is sampled, class-balance, block/time distribution, scoring exclusion) written up in `results/METHODS_FACTS.md` §8. Full pre_cal/post_cal numbers in RESULTS_LEDGER.md's L009.
